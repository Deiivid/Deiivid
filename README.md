## Engineering with Codex

I use **Codex as an engineering system**, not as a code generator in isolation.

```text
Problem → SDD → technical design → TDD → implementation → quality gates → review
```

- **SDD:** scope, boundaries, acceptance criteria and deliberate trade-offs live with the code.
- **TDD:** test strategy covers domain logic, state transitions, integration boundaries and Compose UI.
- **Repository context:** layered `AGENTS.md`, reusable skills and narrow instructions reduce drift and unnecessary context.
- **Controlled delivery:** small changes, explicit validation and evidence before calling work complete.
- **AI orchestration:** specialized roles and repeatable workflows for architecture, UI, QA, performance and release.

My goal is not to ship more generated code. It is to make AI-assisted development **predictable, maintainable and technically accountable**.
